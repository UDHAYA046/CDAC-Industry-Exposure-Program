# CDAC Industry Exposure Program

This repository documents my complete learning journey throughout the **CDAC Industry Exposure Program (2026)**. It contains detailed session notes, assignments, practical exercises, screenshots, resources, and certificates developed during the program.

The primary objective of this repository is to serve as a comprehensive reference for Linux, Cybersecurity, Cloud Computing, Defensive Security, Penetration Testing, and related technologies through structured theory and hands-on practice.
